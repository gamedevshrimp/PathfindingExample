# A 3D top-down pathfinding demo built with [Defold](https://defold.com/)

This example shows how to generate a navigation grid by scanning physical objects in the game world,
and use the result for pathfinding with the A* algorithm.

#### The example uses the extention [A* Path Finding](https://defold.com/assets/apathfinding/)

## How It Works
### 1. Navigation Map Generation
The navigation map is generated by scanning the game world using vertical physics raycasts.
If any raycast hits an object belonging to the `navigation_obstacle` collision group, 
the cell is marked as blocked. Otherwise, it is considered walkable.
### 2. Pathfinding
Once the navigation map is ready it is passed to the [A* Path Finding](https://defold.com/assets/apathfinding/) extetion.
### 3. Agent movement and Target Tracking
After the path is found, the agent follows the generated waypoints.
The target position is checked whenever the agent reaches a waypoint. 
If the target moves to another grid cell, a new path is calculated from the agent's current position.
